# 09: 收藏去重与三视图口径统一

**What to build:** 同一条内容项被收藏两次不再产生重复 id；收藏 / 归档 / 屏蔽三个视图的口径统一——
「全部」排除已归档与被隐藏课程的内容项，「收藏」是「全部」的子集，「归档」「屏蔽」沿用同一套排除规则；
在屏蔽视图里，一条已经收藏过的内容项要显示为「已收藏」。

**Blocked by:** None（可立即开始）

**Status:** ready-for-agent

- [ ] 对同一内容项连续两次置真，收藏集合里只有一条记录
- [ ] 「屏蔽」视图里，已收藏内容的收藏状态显示为已收藏（不再显示成未收藏）
- [ ] 三视图口径统一后，「全部」与「收藏」的计数与列表自洽
- [ ] 既有那几条钉住「置真 append 不去重」的断言**反转为去重语义**；这是有意的行为变更，在交付说明里写清
- [ ] 其余既有收藏/归档/屏蔽断言仍全绿
- [ ] 证据：单测输出 + 设备上一次「收藏 → 屏蔽该课程 → 看屏蔽视图」的截图
