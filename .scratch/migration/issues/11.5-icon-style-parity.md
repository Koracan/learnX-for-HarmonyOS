### Part B：页头信息架构与配色（账号所有者 2026-09-12 追加）

账号所有者给了一张作业页截图并圈出页头四行，原话：

> "当前学期我希望只在"课程"页面显示，"取证覆盖生效"对用户无意义，更新实现应该写相对时间（刚刚更新、1 分钟前更新等），"未完成n"是多余的。背景我希望不继续使用微品红色，用白色即可。总的来说这四项应该只保留更新时间，并和标题压缩到同一行……课程页则把标题、学期、更新时间压缩在同一行……图片仅为示意，请合理调整字号、字体、位置等以保持美观"

**要做的（逐条）**：

1. **作业页头**：只留 **标题 + 相对更新时间**（同一行）。移除 `当前学期 <学期>`、`取证覆盖生效`、`未完成 n`（未完成数在筛选片里已有，不重复）。
2. **课程页头**：**标题 + 学期 + 相对更新时间**。学期**只在这里**出现（这正是参考实现的做法：只有 Courses 传 `defaultSubtitle` = `getSemesterTextFromId(currentSemesterId)`，见 `screens/Courses.tsx:48-50`）。
3. **相对时间**：`刚刚更新` / `1 分钟前更新` / `N 小时前更新` / `N 天前更新`（英文同样处理）。数据源用快照的 `fetchedAtMillis`，**不要**每秒重算刷屏（按需重算即可，例如进入页面/刷新时）。
4. **背景**：页头区域改白色（去掉微品红 tint），正文与卡片的配色/分隔线不动。
5. **通知 / 文件页头**：同一原则（标题 + 相对更新时间）。但**先看那里有没有`未读 n`这类有信息量的计数**——有就保留并提出建议，别为了统一而删掉信息。改动前后各一张截图。

**这是对参考实现的有意偏离（先改台账再改代码）**：参考实现的页头是**居中**的 `HeaderTitle(title, subtitle)`（20px 粗体 + 12px/0.6 透明副标题），
副标题的槽位在**选了筛选时**显示筛选名（`FilterList.tsx:191-201`），列表页默认只给课程传学期；参考实现**没有**"更新时间"这个元素。
我们这里是：① 保留自己的页头版式（左对齐、无导航栏），② 副标题槽位放**相对更新时间**（我们的筛选是筛选片不是下拉，槽位不冲突），③ 只在课程页放学期。
⇒ 在 `docs/reference-quirks.md` **新增一条**（写明参考行为、我们为什么这么排、替代验收标准 = 上面第 1-4 条的界面断言），再做代码。

**被影响的已验收证据（两边都要写）**：

- **ticket 12 的替代验收标准第 3 条**原本写着"界面显示的 semester 就是实际生效值（课程 tab 头部那句）"——改版后它**仍然成立**（课程页头有学期），
  但 **"取证覆盖生效"这枚徽标被移除** ⇒ 覆盖生效的界面信号从此只有"课程页头的学期文本"，其余靠 hilog 的消费点行（`data.courses effective semester=… source=override`）。

### 已查明的实施条件（统筹已核实，可直接用）

1. **同一份字体就在仓库里**（reference 目录被 gitignore，但文件在本地）：
   `reference/learnOH-old/node_modules/react-native-vector-icons/Fonts/MaterialCommunityIcons.ttf`（1,147,844 B）
   与 `MaterialIcons.ttf`（356,840 B）。参考实现用的就是这两个包。
2. **参考实现的图标清单（我用 `name="…"` 扫 `src/**/*.tsx` 得到的起点，38 个不同名字 / 48 处）**：
   `attachment(3) flag(2) checkbox-blank-circle(2) check(2) grade(2) key-variant(2) medal(2) insert-drive-file(2) fullscreen(2)`
   `close search notifications event folder filter-list visibility-off unfinished finished all unread fav archived hidden file-upload check-circle error file-download keyboard-arrow-right cached drive-file-rename-outline delete center-focus-strong person-remove loop rule-folder policy help copyright`
   —— **这只是起点**：tab 栏图标可能在 `*.ts` 的 navigator 配置里（我的扫描只覆盖 `*.tsx`），
   你必须自己重扫一遍并把"清单表"补全（`name=` / `iconName=` / `tabBarIcon` 三条线索）。
3. **推荐路线（三选一，但必须给理由与证据）**：
   - **首选：内嵌上面那份 MCI 字体**（`entry/src/main/resources/rawfile/fonts/` + 运行时注册，`Text('\uXXXX').fontFamily(...)`）。
     理由：与参考实现**同一份字体、同一批 codepoint**，保真度最高，图标名 → codepoint 可以照 `react-native-vector-icons` 的 glyph map 抄。
     代价：hap 体积 +~1.1 MB（如实记录），并要**随仓库附上字体许可证**（Material Design Icons 为 OFL-1.1 —— 把许可证文本一起放进仓库并在 ticket 里写明出处）。
   - 备选：SVG 资源（`resources/base/media/*.svg` + `Image().fillColor()` 着色）。保真度靠手抄，但无字体加载风险。
   - **不要用 `SymbolGlyph`**（台账第 16 条已论证：符号 id 随系统字体版本变化，拿名字猜 id 会得到"编译通过、运行时空格"）。
     若你仍想用它，必须**在设备上逐个符号**证明"渲染非空格 + 颜色可控 + 与参考图形状一致"，否则退回前两条。
4. **Part A 不许顺手改行为/布局**（**Part B 点名的页头改动是例外**）：Part A 只改图标形状与来源，卡片布局、间距、文案、点击行为、取数逻辑一律不动；
   若某个图标尺寸令牌必须调整，写进偏离说明并给替代验收标准。
